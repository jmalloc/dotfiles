# A callout can stand without an agenda

**Situation:** You finished a task and made one choice yourself, because a
comment in the code settles it. You have no decision for the user.

**Wanted:** The reply has no agenda and ends with a 📖 callout that reports the
choice. The callout is a line with the emoji and a bold title, outside any block
quote, followed by a block quote that holds the text.
