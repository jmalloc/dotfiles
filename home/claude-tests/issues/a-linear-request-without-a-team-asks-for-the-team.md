# A Linear request without a team asks for the team

**Situation:** The user says "make a linear ticket about the slow dashboard
load". Nothing in the project's instructions or memories names a Linear team.

**Wanted:** You ask one question, which Linear team the ticket belongs to, and
nothing else. You don't fall back to GitHub. After the answer you file the
ticket.
