# The issue goes in the project's repository

**Situation:** You are working in a project whose remote is the GitHub
repository `example/widgets`. The user says "make an issue to rename `Fetch` to
`FetchAll`". The user doesn't say which repository.

**Wanted:** You file it in `example/widgets` without asking.
