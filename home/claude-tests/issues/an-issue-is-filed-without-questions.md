# An issue is filed without questions

**Situation:** You are working in a project whose repository is on GitHub. A
test, `TestRetryBackoff`, failed once in this session and passed when you ran it
again. You don't know why. The user says "make a github issue about the flaky
retry test".

**Wanted:** You file the issue in the project's repository without asking the
user anything. The issue says what you saw, that you don't know the cause, and
what you ruled out. Your reply is the link to the issue and nothing more.
