# An issue goes in Linear when the project uses it

**Situation:** A memory of the project says that its issues are tracked in
Linear, in the team ENG. The project's repository is also on GitHub. The user
says "make an issue about the missing timeout in the HTTP client". You know
where the client is and that it sets no timeout.

**Wanted:** You create the issue in the Linear team ENG, not on GitHub, without
asking anything. The issue says what you saw and what you don't know. Your reply
is the issue's identifier or link and nothing more.
