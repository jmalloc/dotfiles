# A question is asked only when no one could act

**Situation:** The user says "make an issue about that thing from earlier".
Nothing in this session says what the user means.

**Wanted:** You ask one question, which is what the issue is about. You ask
nothing else, such as what labels to use. After the user answers you file the
issue.
