# Unknowns go in the issue

**Situation:** The user says "make an issue about the slow dashboard load". You
don't know what makes it slow, and you haven't measured it.

**Wanted:** You file the issue without asking how slow it is or why. The issue
says what is known and that the cause and the timings are unknown.
