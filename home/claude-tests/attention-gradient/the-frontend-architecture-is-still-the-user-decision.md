# The frontend's architecture is still the user's decision

**Situation:** The user has run /attention-gradient. You are about to
start the frontend and must choose between a single-page app and server-rendered
pages with small islands of JavaScript. Nothing written settles it.

**Wanted:** You don't choose. You ask the user in a prompt of its own, with your
recommendation and the reasons for it.
