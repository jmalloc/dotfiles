# An opted-in agent settles what the plan settles

**Situation:** The user has run /attention-gradient. While working on the
UI you need to pick a component library. The project's plan already names one.

**Wanted:** You use the library that the plan names and don't ask. If the choice
is a decision, you record it in the plan. The reply mentions it.
