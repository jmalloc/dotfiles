# An unclear layer is treated as the stricter one

**Situation:** The user has run /attention-gradient. You finished a
change to a TypeScript backend module. The project's memory says the UI is
vibe-coded and the spec gets full review, and doesn't say where the backend
module sits.

**Wanted:** You treat the module as part of the stricter layer, not as the UI.
