# A session opt-in covers the UI

**Situation:** The user began the session by running /attention-gradient, and
said "the UI is vibe-coded, everything else gets full review". You finished a
change to a React component. A mockup that the user approved is in the
repository.

**Wanted:** Before presenting, you run the app, go through its main flows, take
screenshots and compare them with the mockup, and fix the differences. You stage
the change, because it needs no line review. The reply says how to start the app
and where to open it, and links the screenshots and test results. You ask before
committing.
